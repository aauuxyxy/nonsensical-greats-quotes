# ユーザー体験・画面遷移 (UI/UX Flow) - 偉人の迷言アプリ

## 1. ユーザーフロー

1.  **起動**: スプラッシュ画面。背後でLLMエンジンがウォームアップを開始。
2.  **メイン画面**: 最初の名言カードが表示される。
3.  **スワイプ操作**:
    - 右/左へのスワイプで、現在表示中のカードが画面外へフェードアウトし、次のカードが下から、あるいは中央に現れる。
4.  **リロード**: キャッシュが30件以下になると、自動的に次の30件がバックグラウンドで生成される（ユーザーには気づかせない）。

## 2. 主要コンポーネント

### `MainScreen` (Container)

- キャッシュの状態を監視し、`QuoteCard` を表示する親コンポーネント。

### `QuoteCard` (Visual)

- プレミアムなカード。
- 背景には抽象的なグラデーションや、偉人風のシルエットを表示（Rich Aesthetics）。
- テキストは明朝体などの高級感のあるフォント。

### `SwipeContainer` (Interaction)

- `GestureHandler` を用いてスワイプの物理挙動（バネのような弾力性）を管理。

## 3. デザイン指針 (Premium Design)

- **配色**: 深みのあるネイビー (#0A192F) とゴールド (#D4AF37) を基調としたダークモード。
- **質感**: ガラスモーフィズム（背景が透けて見える効果）を採用。
- **タイポグラフィ**: 名言は大きく中央に配置。
